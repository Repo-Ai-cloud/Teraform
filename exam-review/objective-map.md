# Terraform Associate 004 Objective Map

This guide maps the course to the official Terraform Associate 004 objectives. The exam targets Terraform 1.12 and includes both Terraform Community Edition and HCP Terraform concepts.

## 1. Infrastructure as Code with Terraform

- 1a Explain what IaC is: Lessons 1, 2
- 1b Describe the advantages of IaC patterns: Lessons 1, 3, 4
- 1c Explain multi-cloud, hybrid cloud, and service-agnostic workflows: Lessons 1, 5, 6

## 2. Terraform Fundamentals

- 2a Install and version Terraform providers: Lessons 2, 5
- 2b Describe how Terraform uses providers: Lessons 5, 6
- 2c Write Terraform configuration using multiple providers: Lessons 5, 30 through 33
- 2d Explain how Terraform uses and manages state: Lessons 3, 22 through 25

## 3. Core Terraform Workflow

- 3a Describe the Terraform workflow: Lessons 3, 4
- 3b Initialize a Terraform working directory: Lessons 4, 5
- 3c Validate a Terraform configuration: Lessons 4, 11
- 3d Generate and review an execution plan: Lessons 4, 8, 14
- 3e Apply changes to infrastructure: Lessons 3, 30 through 34
- 3f Destroy Terraform-managed infrastructure: Lessons 3, 22, 30 through 34
- 3g Apply formatting and style adjustments: Lessons 4, 5

## 4. Terraform Configuration

- 4a Use and differentiate `resource` and `data` blocks: Lessons 7, 30 through 34
- 4b Refer to resource attributes and create cross-resource references: Lessons 7, 8
- 4c Use variables and outputs: Lessons 9, 10, 14
- 4d Understand and use complex types: Lessons 15, 16, 18, 20
- 4e Write dynamic configuration using expressions and functions: Lessons 16, 20, 21
- 4f Define resource dependencies in configuration: Lessons 8, 19, 31
- 4g Validate configuration using custom conditions: Lesson 11
- 4h Understand sensitive data practices, Vault, ephemeral values, and write-only argument awareness: Lessons 12, 33

## 5. Terraform Modules

- 5a Explain how Terraform sources modules: Lessons 26, 28, 29
- 5b Describe variable scope within modules: Lesson 26
- 5c Use modules in configuration: Lessons 26, 27
- 5d Manage module versions: Lessons 28, 29

## 6. Terraform State Management

- 6a Describe the local backend: Lessons 22, 23
- 6b Describe state locking: Lessons 22, 23
- 6c Configure remote state using the backend block: Lesson 22
- 6d Manage resource drift and Terraform state: Lessons 23, 24, 39

## 7. Maintain Infrastructure with Terraform

- 7a Import existing infrastructure into your Terraform workspace: Lesson 24
- 7b Use the CLI to inspect state: Lessons 23, 24
- 7c Describe when and how to use verbose logging: Lesson 36

## 8. HCP Terraform

- 8a Use HCP Terraform to create infrastructure: Lesson 37
- 8b Describe HCP Terraform collaboration and governance features: Lessons 37, 39
- 8c Describe how to organize and use HCP Terraform workspaces and projects: Lesson 38
- 8d Configure and use HCP Terraform integration: Lessons 37, 38
